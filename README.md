# 🏥 Сайт Косметолога Ольги Титовой

Частная косметологическая практика с электронными картами пациентов, управлением визитами и базой препаратов.

## 🚀 Быстрый старт

### Способ 1: Локальный сервер (рекомендуется)

**Windows:**
```cmd
cd server
python start_server.py
```

После запуска откройте браузер по адресу: `http://localhost:3001/`

### Способ 2: Прямое открытие HTML файла

Просто перетащите файл `index.html` в браузер, но **обязательно** включите JavaScript и проверьте консоль браузера (F12) на ошибки!

## 🔧 Локальный хост объяснение

**Локальный хост** — это ваш компьютер, работающий как веб-сервер:
- `localhost` = адрес вашего компьютера
- `3001` = порт (канал связи)

Когда вы открываете `http://localhost:3001/`, браузер обращается к вашему серверу на вашем компьютере!

### Почему нужен локальный хост?

Просто открыть `index.html` напрямую (`file:///...`) **не рекомендуется**, потому что:
1. JavaScript может не работать корректно с относительными путями
2. localStorage может вести себя по-разному
3. Слешевые ссылки могут ломаться

**Правильный способ:**
```cmd
# Через PowerShell или CMD
cd C:\Users\layba\Documents\kosmetolog2_0_1
python server\start_server.py
# Откройте http://localhost:3001/
```

## 🌐 Размещение на GitHub Pages

### Подготовка:

1. Склонируйте репозиторий с ветки `main` или `master`
2. Убедитесь что файлы в папке `public/`:
   ```bash
   ls public/
   # Должны быть: index.html, css/, js/
   ```

3. Загрузите на GitHub:
   - `public/index.html`
   - `public/css/styles.css`
   - `public/js/app.js`
   - `public/js/auth.js`
   - `public/js/store.js`

### Настройка в GitHub:

1. Зайдите в **Settings** репозитория
2. Слева выберите **Pages**
3. В разделе **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main** (или master) → `/ (root)`
   - Click **Save**

4. Подождите 1-2 минуты
5. Откройте `https://ваш-ник.github.io/имя-репозитория/`

## 🆘 Решение проблем

### Сайт не открывается при прямом открытии HTML:
1. Откройте консоль браузера (F12 → Console)
2. Проверьте на красные ошибки
3. Убедитесь что JavaScript включен в настройках браузера
4. Лучше запускайте через локальный сервер

### Данные исчезли после перезагрузки:
- localStorage очищен или вы используете другой браузер
- Сохраняйтесь чаще!

### Не работает редактирование визитов:
1. Проверьте консоль на ошибки JavaScript
2. Обновите страницу (F5)
3. Попробуйте запустить через локальный сервер
